# Quy dinh dong gop cho du an

Xin cam on ban da quan tam den du an nghien cuu.

## 1. Bao cao su co
Neu phat hien loi, vui long mo mot Issue tren GitHub va mo ta chi tiet moi truong thuc thi (phien ban he dieu hanh, Python, card do hoa) kem thong bao loi.

## 2. Quy trinh gui Pull Request
1. Fork repository ve tai khoan cua ban.
2. Tao nhanh moi tu nhanh main de phat trien tinh nang.
3. Kiem tra dinh dang ma nguon tuan thu chuan PEP 8.
4. Gui Pull Request va mo ta nhung thay doi da thuc hien.
